# swing_bot_v2 — 米国株スイングトレード統計的優位性検証システム

> **免責事項**: このシステムは統計的優位性の検証を目的とした学習プロジェクトです。
> 実際の投資成果を保証するものではありません。投資は自己責任で行ってください。

---

## プロジェクト概要

米国株のスイングトレードにおいて、**「株価予測」ではなく「統計的優位性」** に基づいた
売買判断を自動化するシステム。

### 設計思想の核心

> コイントス（50:50）を、統計的優位性とリスクリワード比によって
> 長期的にプラスになる方向へ傾けることがシステムトレードの本質である。

- **株価予測はしない**: 「次に上がるか」ではなく「この条件下では勝率がわずかに高い」を積み重ねる
- **説明可能な指標のみ使用**: なぜその指標を使うのかを理論的に説明できるものだけを採用
- **過学習を意識的に回避**: パラメータの最適化よりも汎用性を重視
- **感情の排除**: プログラムによる機械的な判断でAXTI（-29%）のような塩漬けを防ぐ

## バックテスト結果

### 検証条件
- 対象: S&P500構成銘柄（約500銘柄）
- 期間: 過去5年分
- 総トレード数: **20,554件**

### 結果サマリー

| 指標 | 値 |
|---|---|
| 勝率 | 34.5% |
| 平均利益 | +6.47% |
| 平均損失 | -2.94% |
| 実際のRR比 | 2.20 |
| 期待値 | **+0.30%/トレード** |
| コイントスからの優位性 | **+1.30%** |

### 統計的優位性の根拠

RR比2.0の場合、損益分岐点となる勝率は **33.3%**。

期待値 = 勝率 × 平均利益 - 負け率 × 平均損失
= 0.345 × 6.47% - 0.655 × 2.94%
= +0.30%/トレード


20,627件のサンプル数における95%信頼区間（二項分布の正規近似）:
- 勝率: **33.8% 〜 35.1%**
- 信頼区間の下限33.8% > 損益分岐点33.3%
- **95%の確率で勝率は損益分岐点を上回ることを統計的に確認**

【限界】
- 生存者バイアス: 現在のS&P500銘柄のみで検証
- 過去への適合: この数字が将来も続く保証はない
- 信頼区間はサンプリング誤差のみを考慮（市場環境の変化は含まない）

長期下落トレンドにおける損失は受け入れるべきリスクとして設計上織り込み済み。

## 戦略の設計

### エントリー条件（3条件）

#### ① 20日移動平均線が上向き
```python
ma20 > ma20.shift(5)  # 5日前より現在の20日線が高い
```
**理由**: 約1ヶ月の平均コストを示す20日線が上向きであることは、
直近の買い手が全員含み益の状態を意味し、売り圧力が少ない環境を示す。

#### ② 乖離率 +3%〜+8%
```python
deviation = (close - ma20) / ma20
0.03 <= deviation <= 0.08
```
**理由**: 
- 下限(+3%): 移動平均線を上抜けたことを確認（トレンド確認）
- 上限(+8%): 「平均回帰」の性質により上がりすぎた銘柄は下落しやすい（高値掴み防止）

#### ③ VIX < 23.5（恐怖指数フィルター）
```python
vix < 23.5
```
**理由**: VIXは市場参加者の「恐怖度」を数値化した心理指標。
VIX > 23.5は市場が不安定な状態を示し、個別株も巻き込まれやすい。
通常相場のVIXは12〜20程度で推移するため、このフィルターが
発動するのは年に数回程度（大数の法則を妨げない設計）。

### エグジット条件

| 条件 | 内容 | 理由 |
|---|---|---|
| 利確 | +6% | RR比2.0を維持するため |
| 損切り | -3% | Woodstockの逆指値注文で自動化 |
| 強制決済① | 5営業日後に含み損 | 塩漬け防止（負けを早く切る） |
| 強制決済② | 10営業日後 | スイングトレードの想定期間超過 |

### 資金管理（ケリー基準）
Kelly% = 勝率 - (負け率 / RR比)
= 0.345 - (0.655 / 2.0)
= 0.017（1.7%）

ハーフケリー（安全係数0.5）:
推奨投資割合 = 1.7% × 0.5 = 0.85%/トレード


フルケリーではなくハーフケリーを採用する理由:
- バックテストと実運用の乖離（過学習・生存者バイアス）
- 心理的な耐えやすさ
- ドローダウンの抑制

## システム構成

### ファイル構成
swing_bot_v2/
├── config.py # 戦略パラメータの一元管理

## システムの限界と注意点

### バックテストの限界

| 限界 | 内容 | 影響 |
|---|---|---|
| 生存者バイアス | 現在のS&P500銘柄のみで検証 | 実際のリターンは10〜15%低い可能性 |
| スリッページ | 実際の約定価格との差は未考慮 | 特に流動性が低い銘柄で影響大 |
| 為替変動 | ドルベースで計算 | 円換算の損益とは異なる |
| 過学習リスク | 5年間のデータに最適化されてる可能性 | 将来の相場では性能が低下する可能性 |

### 運用上のリスク
対応困難なリスク:
→ 為替介入（VIXに反映されにくい）
→ 個別銘柄の突発的なニュース（決算ミス等）
→ 2022年のような急激な政策転換

対応済みのリスク:
→ 感情的な損切り遅延（逆指値注文で自動化）
→ 塩漬け（強制決済ルール）
→ 市場全体の急落（VIXフィルター）
